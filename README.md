# Arydebts Solution

Primera versión funcional de Arydebts: una PWA móvil para organizar ingresos, gastos y deudas y convertirlos en un plan semanal accionable.

## V1
- Dashboard dinámico y responsive dark/neon.
- Registro de ingresos, gastos y deudas.
- Detección de gastos hormiga.
- Plan semanal calculado con gastos esenciales, mínimos, colchón y ataque de deuda.
- Persistencia local con localStorage.
- Moneda base configurable y formato internacional.

> Esta V1 es una herramienta educativa de planificación financiera y no garantiza resultados. La sincronización segura entre dispositivos se añadirá con backend en una fase posterior.
