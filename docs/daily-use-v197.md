# Daily use V197

Instant entry groups Spanish and Portuguese digits with dots while preserving the entered amount text. Decimal fractions use a comma; pasted dot fractions are accepted. English follows its locale conventions. Numeric example buttons keep an existing expense name. Very large amounts retain their original digits in amountText197, but calculations in the existing Number-based engine are approximate and the input shows that limitation.

Date checkboxes default to unchecked. New undated one-time expenses count in their registration month via recordedAt197, without inventing a manual date. Removing an existing date preserves its accounting month through accountedDate197. Legacy undated records are not assigned today's date on edit. Recurring estimates remain separate from recorded payments. Every two, three and four days use annualized monthly factors 365/24, 365/36 and 365/48.

The ISO currency selector changes the profile's display currency atomically. It does not convert amounts or provide multiple currency wallets. Interface translations remain Spanish, English and Portuguese.

Cards and tabs enter arrangement after an 1800 ms hold. Scrolling movement before activation cancels the hold. Card placement and order are saved per user and screen, including moves between card containers. Canceled drags and failed storage writes restore the original DOM. Input controls do not initiate arrangement. Alt plus arrow keys remains available. Done exits arrangement.

The motivational quote defaults to immediately below search and respects saved custom placement. A brief low-gain sine tone is available only in immersive mode after a trusted interaction, with a saved mute preference in appearance settings.
